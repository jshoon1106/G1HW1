로그 형식
  [가상 시각] 노드 | 이벤트 | 상태 | 내용

상태
  INFO    일반 진행 정보
  SUCCESS 연결, 처리, 이전, 종료 성공
  FAIL    처리 실패, Queue 초과, 연결 실패, 전체 처리 제한시간 초과
  WARN    Queue 70% 초과, 잘못된 프로토콜 메시지, 중복 결과, ACK 제한시간 초과

이벤트
  INIT       Master 시작, KV 작업 5,000개 생성
  CONNECT    Worker 연결, 연결 해제
  RECV       Master 작업 수신
  DISTRIB    Master 작업 배정, 전체 처리 완료
  RESULT     Worker 성공·실패 결과 수신
  PROC       Worker 작업 처리 결과
  QUEUE      Queue 용량 경고, 초과 거부
  LB         Worker 간 Queue 조회, P2P 작업 이전·수신·ACK 확인, 이전 KV 번호 기록
  PROTO      알 수 없거나 형식·범위가 잘못된 네트워크 메시지
  KV         최종 Key-Value 저장소 전체 출력
  STAT       Master·Worker 최종 통계
  TERMINATE  정상 종료 신호, 종료 완료

추가 규칙
  RESULT 로그는 20% 처리 실패와 Queue 초과 거부를 구분한다.
  동일 taskId와 attempt의 중복 RESULT는 최초 1건만 반영한다.
  P2P 전송은 transferId로 중복 수신을 방지한다.
  Master 통계에는 처리 실패 수와 Queue 초과 거부 수를 별도로 기록한다.
  장애 재할당 수는 20% 처리 실패와 Worker 연결 해제로 인한 재할당만 집계한다.
  각 Worker의 장애 재할당 발생 수는 해당 Worker의 20% 처리 실패 횟수로 기록한다.
  각 Worker는 재시도 작업 수신 수를 별도로 기록한다.
  P2P 이벤트 수와 P2P로 이동한 작업 수는 별도 집계한다.
  각 Worker는 P2P 전송 이벤트, 수신 이벤트, 두 값의 관여 합계를 구분하여 기록한다.
  Worker별 P2P 전송 이벤트 합계와 수신 이벤트 합계는 각각 Master 전체 P2P 이벤트 수와 일치한다.
  각 노드 STAT에는 처리량, 성공·실패, 평균 대기시간, P2P 이벤트, 장애 재할당, 전체 수행시간을 기록한다.
